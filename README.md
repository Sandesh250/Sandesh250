## 🚀 Featured Projects

### 🖨️ E-erox: Smart Automated Printing System
> Upload a PDF, choose print options, pay online, and the shop prints it automatically.

- **4-layer architecture:** React student portal, Node.js API, Electron shop app (with a Python fallback agent), PostgreSQL + AWS S3
- **Server-side PDF pipeline:** page ranges, N-up layout and a **QR token cover page** merged into the document; live grayscale preview in the browser
- **Silent printing** with Electron and `pdf-to-printer`, per-paper-size printer routing (A4/A3) and an auto-print polling agent
- **Cashfree** payments tied to job creation; **Vercel proxy** fix for mobile ISP reliability
- Private S3 files served through short-lived pre-signed URLs

`React` `Node.js` `Electron` `Python` `PostgreSQL` `AWS S3` `Cashfree`

### 🔐 Comparative Analysis of OTP Generation Algorithms
> Six OTP algorithms, one secure 2FA system, measured and attacked.

- Implemented and benchmarked **TOTP, HOTP, S/KEY (Lamport chains), CSPRNG, SHA-256 and modulo OTPs** across **1,000+ iterations**
- Studied **space-time trade-offs** (S/KEY: O(1) verification vs O(N) setup) and **forward secrecy**
- **JWT-based authentication** with replay-token tracking, use-once enforcement, rate limiting, bcrypt and an audit trail
- Interactive React dashboard with live benchmark charts and an algorithm simulator

`Python` `Flask` `React` `bcrypt` `SQLite`

[![Repo](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github)](https://github.com/Sandesh250/otp-algorithms-analysis)

### 🧭 MyCareerPilot: AI Career Guidance Platform
> Upload a resume, get an ATS score, top-3 career matches and a learning roadmap.

- **Next.js + FastAPI** platform; PDF parsing with PyPDF2
- **Rule-based ATS score** (50% skill match, 30% keywords, 20% completeness) so every point is explainable
- **Random Forest** career recommender (top-3 with reasoning, AI-risk and market trend)
- **Drizzle ORM + Neon Postgres + Auth.js**; personalised roadmaps from skill gaps; Groq-powered coach that *explains* but never scores

`Next.js` `TypeScript` `Tailwind CSS` `FastAPI` `scikit-learn` `PostgreSQL`
